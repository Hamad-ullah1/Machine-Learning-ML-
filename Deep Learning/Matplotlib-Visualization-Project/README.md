# Matplotlib Visualization Project

This project contains practical implementations of **Data Visualization using Matplotlib**. It demonstrates how different types of charts and plots can be used to understand, analyze, and present data visually.

## 📌 What is Data Visualization?

**Data Visualization** is the process of representing data using visual elements such as charts, graphs, and plots.

Visualization makes it easier to:

* Understand data
* Identify patterns
* Compare values
* Find trends
* Detect outliers
* Communicate insights

## 📊 Visualizations Covered

### 1. Line Plot

Used to show trends and changes over time.

### 2. Scatter Plot

Used to visualize the relationship between two numerical variables.

### 3. Histogram

Used to show the distribution of numerical data.

### 4. Box Plot

Used to understand data distribution and identify outliers.

### 5. Bar Plot

Used to compare values across different categories.

### 6. Pie Chart

Used to show proportions or percentages of a whole.
