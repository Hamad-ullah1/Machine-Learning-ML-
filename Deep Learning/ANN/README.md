# Artificial Neural Network (ANN)

This folder contains learning materials and implementations of **Artificial Neural Networks (ANNs)**, one of the fundamental concepts of Deep Learning.

## 📌 What is an Artificial Neural Network?

An **Artificial Neural Network (ANN)** is a machine learning model inspired by the structure of the human brain. It consists of interconnected artificial neurons that learn patterns from data and make predictions.

## 🧠 Basic Structure of an ANN

An ANN is generally composed of three types of layers:

```text id="y4f2qj"
Input Layer → Hidden Layer(s) → Output Layer
```

### 1. Input Layer

Receives the input features.

**Example:**

```text id="5nx5g0"
Age, Salary, Experience
```

### 2. Hidden Layers

Process the input data using weights, biases, and activation functions.

### 3. Output Layer

Produces the final prediction.

**Example:**

```text id="j6s2q1"
0 → No
1 → Yes
```

## 🔄 How an ANN Works

The general process is:

```text id="x0o0b9"
Input Data
    ↓
Weighted Sum
    ↓
Activation Function
    ↓
Hidden Layers
    ↓
Output Prediction
```

During training, the network:

1. Receives input data
2. Makes a prediction
3. Calculates the error
4. Adjusts weights and biases
5. Repeats the process to improve predictions

## ⚡ Activation Functions

Activation functions help neural networks learn complex patterns.

Common activation functions include:

* ReLU
* Sigmoid
* Tanh
* Softmax
