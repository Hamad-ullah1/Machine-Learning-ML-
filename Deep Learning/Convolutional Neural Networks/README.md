# Convolutional Neural Networks (CNNs)

This folder contains learning materials and implementations of **Convolutional Neural Networks (CNNs)**, a deep learning architecture mainly used for processing and analyzing image data.

## 📌 What is a Convolutional Neural Network?

A **Convolutional Neural Network (CNN)** is a type of deep neural network designed to automatically learn important features from images.

CNNs can recognize patterns such as:

* Edges
* Shapes
* Textures
* Objects

They are widely used in **Computer Vision** applications.

## 🧠 Basic CNN Architecture

```text id="d6c1se"
Input Image
     ↓
Convolutional Layer
     ↓
Activation Function (ReLU)
     ↓
Pooling Layer
     ↓
Flattening
     ↓
Fully Connected Layer
     ↓
Output
```

## 🔍 Main Components

### 1. Convolutional Layer

Applies filters to an image to detect important features such as edges and patterns.

### 2. ReLU Activation Function

Introduces non-linearity and helps the network learn complex patterns.

### 3. Pooling Layer

Reduces the size of feature maps while preserving important information.

Common types include:

* Max Pooling
* Average Pooling

### 4. Flattening

Converts the 2D feature maps into a 1D vector.

### 5. Fully Connected Layer

Uses the extracted features to make the final prediction.
