# Natural Language Processing (NLP) Using RNNs

This folder contains learning materials and implementations of **Natural Language Processing (NLP) using Recurrent Neural Networks (RNNs)**.

## 📌 What is NLP using RNNs?

**Natural Language Processing using RNNs** involves using Recurrent Neural Networks to process and understand sequential text data.

Since text is made up of sequences of words, RNNs can use information from previous words to help understand and predict the next parts of a sentence.

### Example

```text
Input:
I am learning

Prediction:
Python
```

The RNN learns patterns from previous words to predict the next word or classify the text.

## 🧠 How RNNs Process Text

```text
Word 1 → Word 2 → Word 3 → Word 4
   ↓        ↓        ↓        ↓
              RNN
               ↓
        Prediction / Output
```

The hidden state carries information from previous words through the sequence.
