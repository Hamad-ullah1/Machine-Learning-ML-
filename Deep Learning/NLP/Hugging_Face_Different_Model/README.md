# Hugging Face Different Models

This folder contains learning materials and implementations using different models from the **Hugging Face** ecosystem for Natural Language Processing and Generative AI tasks.

## 📌 What is Hugging Face?

**Hugging Face** is an open-source AI platform that provides pre-trained models, datasets, and tools for Machine Learning and Deep Learning.

It makes it easier to use powerful pre-trained models for tasks such as:

* Text Classification
* Sentiment Analysis
* Text Generation
* Question Answering
* Text Summarization
* Translation
* Image Processing
* Audio Processing
