# Generative AI

This folder contains learning materials and implementations related to **Generative Artificial Intelligence (Generative AI)**, a field of AI that focuses on creating new content based on patterns learned from existing data.

## 📌 What is Generative AI?

**Generative AI** is a branch of Artificial Intelligence that uses machine learning and deep learning models to generate new content such as:

* Text
* Images
* Audio
* Video
* Code

Unlike traditional AI systems that mainly classify or predict existing data, Generative AI can **create new content**.

## 🧠 Basic Generative AI Workflow

```text id="c6j2m1"
Training Data
     ↓
AI Model Learns Patterns
     ↓
User Input / Prompt
     ↓
Generated Content
```
