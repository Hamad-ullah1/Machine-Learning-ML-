# Natural Language Processing (NLP)

This folder contains learning materials and implementations related to **Natural Language Processing (NLP)**, a field of Artificial Intelligence that enables computers to understand and process human language.

## 📌 What is Natural Language Processing?

**Natural Language Processing (NLP)** is a branch of Artificial Intelligence that focuses on enabling computers to understand, process, analyze, and generate human language.

NLP works with data such as:

* Text
* Documents
* Messages
* Reviews
* Speech

## 🧠 Basic NLP Workflow

```text
Raw Text
   ↓
Text Preprocessing
   ↓
Tokenization
   ↓
Feature Extraction
   ↓
Machine Learning / Deep Learning Model
   ↓
Prediction
```

## 🎯 Learning Objectives

By studying NLP, you will learn:

* How computers process human language
* How text data is cleaned and prepared
* How text is divided into tokens
* How common and unnecessary words are handled
* How text is converted into numerical features
* How machine learning and deep learning models work with text data
* How NLP can be used for classification and sentiment analysis
