# NLP Fundamentals

This folder contains the fundamental concepts and techniques of **Natural Language Processing (NLP)**.

## 📌 What is Natural Language Processing?

**Natural Language Processing (NLP)** is a branch of Artificial Intelligence that enables computers to understand, process, analyze, and work with human language.

NLP allows machines to work with:

* Text
* Documents
* Messages
* Reviews
* Speech

## 🧠 Basic NLP Workflow

```text
Raw Text
   ↓
Text Preprocessing
   ↓
Tokenization
   ↓
Text Representation
   ↓
Machine Learning / Deep Learning
   ↓
Prediction or Analysis
```

## 🔤 Tokenization

**Tokenization** is the process of dividing text into smaller units called tokens.

### Example

```text
Sentence:
I am learning Python.

Tokens:
["I", "am", "learning", "Python"]
```

## 🧹 Text Preprocessing

Text preprocessing prepares raw text for analysis and machine learning.

Common preprocessing steps include:

* Converting text to lowercase
* Removing punctuation
* Removing unnecessary characters
* Removing stop words
* Stemming
* Lemmatization
