# Classification

This folder contains implementations and learning materials related to **Classification in Machine Learning**.

## 📚 Topics Covered

### 1. Logistic Regression

A supervised learning algorithm used to predict the probability of a categorical outcome.

### 2. Multiclass Classification

A classification problem where the model predicts one class from more than two possible classes.

### 3. Support Vector Machines (SVM)

A supervised learning algorithm that finds the best boundary to separate different classes.

### 4. Decision Trees

A tree-based algorithm that makes predictions by applying a sequence of decision rules.

### 5. Random Forests

An ensemble learning algorithm that combines multiple decision trees to improve prediction performance.

## 🎯 Learning Objectives

Through these notebooks and examples, you will learn:

* The difference between binary and multiclass classification
* How classification algorithms make predictions
* How decision boundaries separate different classes
* How Logistic Regression works
* How Support Vector Machines classify data
* How Decision Trees make decisions
* How Random Forests combine multiple decision trees
* How to train and evaluate classification models
